Happ на ПК: установка и настройка

На компьютере Happ работает так же, как на телефоне: добавили ссылку подписки — выбрали сервер — подключились. Ниже — по шагам для Windows и macOS.

Попробовать Krispy за 1 ₽

Установка на Windows

  1. Скачайте установщик Happ для Windows с официального сайта разработчика (ссылка есть в кабинете Krispy).
  2. Запустите установщик и следуйте подсказкам. Windows может спросить разрешение на изменение сетевых настроек — это нормально для VPN-клиента.
  3. Откройте Happ и добавьте ссылку подписки из буфера обмена.

Установка на macOS

  1. Установите Happ из Mac App Store или с сайта разработчика.
  2. При первом подключении macOS попросит разрешить добавление VPN-конфигурации — подтвердите.
  3. Добавьте ссылку подписки и выберите сервер.

А если у вас Linux

Krispy VPN поддерживает Linux. Выберите в инструкции личного кабинета свою платформу — там указано, какой клиент использовать.

Компьютер и телефон на одной подписке

Одна подписка Krispy подключает до 10 устройств. Ссылку можно добавить и на ноутбук, и на телефон, и на планшет — отдельно платить за каждое устройство не нужно.

Вопросы

Happ на ПК бесплатный?

Приложение бесплатное, но для подключения нужна подписка от сервиса.

Почему Windows просит права администратора?

VPN-клиенту нужно настроить сетевой адаптер, без этого он не сможет направить трафик через защищённый канал.

Можно ли использовать Happ и INCY одновременно?

Лучше нет: два VPN-клиента, включённые одновременно, мешают друг другу.
